Week 2 · Day 6 · Notes

Fair comparisons without a right answer

Week 1 counted right and wrong answers. This week the answers are summaries, so you compare them in pairs with a judge, and guard against the judge's biases.

1

The head-to-head setup

  • 200 test articles the model never trained on; one greedy summary per run (A = base, B = chosen checkpoint).
  • Held-out judge, never the training judge: run B was trained to please it.
  • Both orders for every pair; keep a winner only if both orders agree, else tie (Day 1's pairwise_debiased).
2

Win rate, sign test, interval

win rate (B) = (wins + ½ · ties) / n
sign test    = two-sided exact binomial on wins vs losses (ties dropped)    # week 1's McNemar idea
interval     = bootstrap: resample comparisons 2,000×, middle 95%
ExampleValue
B wins 110, A wins 70, ties 20win rate 120 / 200 = 60%
Sign test on 110 vs 70p ≈ 0.004 (under 1 in 100 by luck)
Bootstrap 95% intervalabout 53–67%
3

Length control

Judges like longer answers, and RL against a judge often makes answers longer. So part of a win rate can be length, not quality. First, report each run's average length.

Then report a length-controlled win rate. Length-controlled AlpacaEval (Dubois et al., 2024) fits a simple model of the judge's preference that includes the length difference, and asks what the preference would be at equal length. It raised the benchmark's Spearman correlation with Chatbot Arena rankings from 0.94 to 0.98.

P(B wins) = σ(a + b · Δlength)        # fit a, b by logistic regression; ties = 0.5 targets
length-controlled win rate = σ(a)     # the win rate when Δlength = 0

This is a simplified version of their method (they include more terms), and fine for your scale.

4

People, more checkpoints, a second judge

  • Spot check: 30 pairs, blind to which run is which. If the judge agrees with you on ~25, good; near 15, it's guessing on this task.
  • Several checkpoints: compare them in pairs and fit Bradley-Terry ratings (Day 5's fit_bt), the way Chatbot Arena ranks models.
  • A second held-out judge from another family: agreement raises confidence; disagreement goes in the report.

Glossary

Head-to-head
Two runs answer the same prompt; a judge picks the better answer.
Win rate
(wins + ½ ties) / number of comparisons.
Sign test
Exact binomial test on wins vs losses, ignoring ties.
Bootstrap interval
Resample comparisons many times; the middle 95% of win rates.
Length bias
Judges preferring longer answers regardless of quality.
Length-controlled win rate
The win rate a model of the judge predicts at equal length.
Logistic regression
Fits P(win) = σ(a + b·x) to data.
Spot check
A small blind sample you grade yourself to check the judge.
Bradley-Terry ratings
One rating per model, fitted from pairwise results.
Chatbot Arena
A public leaderboard that ranks models from human pairwise votes.

Tasks

  1. Write eval/compare_judged.py with:
    • win_rate(verdicts): verdicts are "A", "B" or "tie"; B's win rate with ties as half; ValueError if empty or bad labels
