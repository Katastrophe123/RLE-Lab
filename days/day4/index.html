Day 4 · Notes

Find the holes before the model does

A model sampling thousands of answers finds verifier holes by accident. Your job today is to find them first, on purpose.

1

Reward hacking

The model raises its reward without doing the task you meant. Not cleverness or malice: RL pushes probability toward whatever scores well, shortcuts included. The defence is a verifier with fewer shortcuts.

SettingWhat gets learnedThe verifier's mistake
Coding agentEdit the tests instead of fixing the code"Tests pass" without protecting the tests
SummariserCopy the sourceSimilarity score rewards overlap
Chat modelLonger and longer answersThe judge prefers length
Your math verifier<answer>7 2</answer> scores 1.0Normalising deleted inner spaces

Further reading: Lilian Weng, "Reward Hacking in Reinforcement Learning" (Nov 2024).

2

Audit with hand labels

  1. Take 100 completions your verifier rewarded during Day 3. Label each: truly correct? Precision = truly correct ÷ 100.
  2. Take 50 that scored zero. Count the right answers it missed. Missed-answer rate = missed ÷ 50.
  3. Report each with an interval. With k false positives in n labels, the 95% Wilson interval tells you how sure you are (try it in the Playground). 20 labels give a wide range; 100 give a useful one.

full-width ７２Python's \d matches Unicode digits, and Decimal accepts themASCII digits only (re.ASCII)
 
NUM = re.compile(r"^-?\$?(\d{1,3}(,\d{3})+|\d+)(\.\d+)?$", re.ASCII)

def normalize(s):
    if s is None: return None
    s = s.strip()                         # outside spaces only
    if not NUM.match(s): return None
    return Decimal(s.replace("$", "").replace(",", ""))
5

The trade, and the limit

Trade: strict rules cost recall. 1 000 with a space, or full-width digits, now score 0 even when right. A missed right answer wastes a little signal; a rewarded wrong one teaches the wrong lesson. Choose on purpose and write it down.

Limit: an answer-only verifier can't tell a lucky guess from real reasoning. Nonsense steps followed by <answer>72</answer> still score 1.0. Fixing that needs process checks or a judge that reads the reasoning, each gameable in its own way. Week 2 material.

Glossary

Reward hacking
Raising the reward without doing the task you meant.
Audit
Hand-label real completions to measure how often the verifier is wrong.
Missed-answer rate
Of zero-reward completions, the share that were actually right.
Confidence interval
The range your true precision probably lies in. More labels, narrower range.
Attack catalog
A list of tricky completions, each with the reward it should get.
Regular expression
A pattern for matching text, like 'digits, then an optional decimal part'.
Unicode
The standard that covers every script's characters, including non-English digits.
ASCII digits
The plain 0–9 characters.
Regression test
A test that keeps a fixed bug from coming back.
Process check
Grading the reasoning steps, not just the final answer.
