Why small gaps can be noise

On 200 problems, +2 points is just 4 more correct answers. Changing only the random seed can move a small model by a few points either way. A gap smaller than that wobble is not a finding yet.

So don't compare the two totals. Compare question by question. Every question lands in one of four boxes:

v2 rightv2 wrong
v1 rightboth right (tells you nothing)only v1 right
v1 wrongonly v2 rightboth wrong (tells you nothing)

Only the two "only" boxes, the disagreements, carry information about which run is better.

3

McNemar's test: the coin-flip check

If the runs were equally good, each disagreement would be a fair coin flip. The p-value is how often a fair coin gives a split at least as lopsided as yours. Below 0.05 is the usual bar for "probably real".

from math import comb
def mcnemar_exact(only_a, only_b):
    n = only_a + only_b
    if n == 0: return 1.0
    k = min(only_a, only_b)
    return min(1.0, 2 * sum(comb(n, i) for i in range(k + 1)) / 2 ** n)

Recommended reading: Evan Miller, "Adding Error Bars to Evals" (Anthropic, 2024), which argues for exactly this question-level, paired analysis.

4

Paired bootstrap, and the verdict

Bootstrap: treat your 200 problems as a bag. Draw 200 at random with repeats, recompute the accuracy gap (v2 − v1) on that draw, and repeat 2,000 times. The middle 95% of those gaps is your interval. If it includes 0, you can't claim a win.

Read rollouts too. Hand-label 50 answers v2 rewarded. Did precision rise? Did length change? Higher accuracy with a brand-new hack isn't better.

Verdict: write exactly one of v2 better, v2 worse, or can't tell yet, with the p-value and interval. "Can't tell" is honest and common at this scale. The fix is more problems or more seeds, not a louder claim.

Glossary

Noise
Random wobble: numbers that move even when nothing real changed.
Seed
The starting number for randomness. A different seed gives a slightly different run.
Paired comparison
Both runs on the same questions, compared one question at a time.
Disagreement
A question one run got right and the other got wrong.
McNemar's test
Checks if the disagreements split more lopsidedly than coin flips would.
p-value
How often luck alone would give a result at least this extreme. < 0.05 = probably real.
Bootstrap
Resample your problems with repeats many times to see how much a number wobbles.
Throughput
How much work gets done per hour.
Inference engine
Software built only to generate text fast, e.g. vLLM or SGLang.
Colocated
Generation and training share the same GPUs and take turns.
Disaggregated
Separate GPU pools for generation and training.
Weight sync
Sending the trainer's new weights to the generators after each update.
Straggler
The slowest answer in a batch, which everyone else waits for.
Asynchronous RL
Generators keep going while the trainer trains; answers are slightly stale.
Sandbox
A sealed container with time limits and no internet, for running untrusted code.
