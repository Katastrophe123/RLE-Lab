The objective, line by line

GRPO works, but some of its normalisation choices quietly bias what the model learns. Knowing them is what lets you read a paper's recipe and set TRL correctly.

The clipped objective

For each token, the ratio r = π_new(token) / π_old(token) compares the policy being trained with the one that sampled the rollout. The per-token objective (to maximise) is:

objective = min( r · A,  clip(r, 1 − ε_low, 1 + ε_high) · A )      # usually ε = 0.2
AdvantageRatioWhat happens
A > 0 (good answer)r > 1 + εCapped: gradient is 0. The token already rose enough this step.
A > 0r < 1 + εNormal push up
A < 0 (bad answer)r < 1 − εCapped: gradient is 0. The token already fell enough.
A < 0r > 1 − εNormal push down, unclipped if r grew (the min keeps the worse case)
3

The KL leash

loss = −objective + β · KL(π ‖ π_ref), where π_ref is a frozen copy of the starting model. It slows drift and some reward hacking, and costs memory for the reference model.

DAPO sets β = 0, arguing that for long reasoning the model needs to move far from where it started. Recent TRL versions also default to beta=0.0, and only log a kl curve when β > 0. With no leash, the verifier is the only thing steering the model, which is why Days 2 and 4 matter.

4

Bias 1: dividing by the group's std

Group rewardsGRPO (÷ std)Dr. GRPO (mean only)
[1, 0, 0, 0] real win+1.73, −0.58 ×3+0.75, −0.25 ×3
[0.1, 0, 0, 0] format bonus+1.73, −0.58 ×3+0.075, −0.025 ×3

Dividing by the std makes every group's advantages the same size, however small the reward gap. Groups with little spread (nearly all right or nearly all wrong) get their tiny differences inflated. Dr. GRPO (Liu et al., 2025) calls this a difficulty bias and drops the division. TRL: scale_rewards ("group", "batch", or off).

5

Bias 2: averaging per answer

GRPO's loss averages over each answer's own tokens, then over answers. A token's weight is 1 / (its answer's length). A 500-token wrong answer spreads its penalty over 500 tokens: each gets a fifth of what a 100-token wrong answer's tokens get. Long wrong answers become cheap, and lengths drift up. (For right answers the effect flips: short ones get a stronger push.)

grpo     = mean over answers of ( Σ token losses / |answer| )     # length bias
dr_grpo  = Σ all token losses / ( G · max_completion_length )      # constant
dapo     = Σ all token losses / total tokens in the batch          # token-level

DAPO's four fixes (Yu et al., 2025)

FixProblem it solvesTRL setting
Clip-higher (ε_low 0.2, ε_high 0.28)Entropy collapse: low-probability tokens can't grow, so exploration diesepsilon, epsilon_high
Dynamic samplingGroups that all score the same give zero gradientNot built in; filter in your data pipeline
Token-level lossLength bias of per-answer averagingloss_type="dapo"
Overlong shapingTruncated answers get noisy rewardsmask_truncated_completions=True (filtering)

Their ablation on Qwen2.5-32B, AIME 2024: naive GRPO 30, then overlong filtering 36, clip-higher 38, soft overlong punishment 41, token-level loss 42, dynamic sampling 50. They also drop the KL term.

TRL option names and defaults have changed across versions (for example, loss_type's default). Check the GRPOConfig docs for the version you have installed.

Glossary

Ratio
π_new(token) ÷ π_old(token). 1 means the token's probability hasn't changed.
Objective
The score each training step tries to raise.
Gradient
The direction (and size) an update pushes each token's probability.
Policy gradient
The simplest update: advantage × ratio, with no limit.
Clipping (ε)
Caps the ratio to a band like 0.8–1.2. A speed limit per token.
Reference model
A frozen copy of the model from before training.
KL penalty (β)
Subtracts drift from the reference model. β = 0 turns it off.
Std division bias
Dividing by the std makes tiny reward gaps look as big as real ones.
Length bias
Per-answer averaging gives long answers' tokens less weight each.
Entropy collapse
The model stops exploring and always answers the same way.
Ablation
Add or remove one piece at a time to see what each is worth.
AIME
A hard high-school math competition used as a benchmark.
Dynamic sampling
Drop groups where every reward is equal; resample to fill the batch.
