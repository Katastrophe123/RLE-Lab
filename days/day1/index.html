Where the reward comes from

RLHF

A learned model gives the reward. People compare pairs of answers, a reward model learns their taste, and it scores rollouts.

  • Good for fuzzy goals: tone, helpfulness
  • Risk: the reward model can be fooled
RLVR · this week

A program gives the reward. Did the code pass its tests? Is the final number right?

  • Cheap, fast, precise, deterministic
  • Limit: only tasks you can check; a buggy checker gets gamed

numpy defaults to population std (ddof=0); PyTorch and TRL use sample std (ddof=1), so their numbers are a bit smaller, e.g. +1.50 instead of +1.73. Signs and ranking never change.

6

The zero-signal trap

If every answer to a prompt scores the same, every advantage is 0. That prompt teaches nothing, but you paid for all G rollouts. Too-easy and too-hard prompts both waste compute; learning happens on mixed groups. Try the difficulty simulator in the Playground to see how sharply this bites.
